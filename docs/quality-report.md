### 「以未登入狀態和另一個帳號存取不該存取的資料」

本版本沒有帳號、沒有伺服器，資料只存在各自的瀏覽器。端對端測試以「另一個瀏覽器」模擬另一位使用者，確認**看不到**第一位使用者的回報。

### 尚存的風險（可接受，已記錄）

- **開發工具有 4 個中度漏洞**（`glob`、`minimatch`，屬於產生 service worker 的打包工具）。只在打包時執行，不會進到網站裡。等上游套件更新後再升級。
- **CSP 允許 inline style**（`style-src 'unsafe-inline'`）：地圖套件 Leaflet 需要。風險低，因為程式（script）仍然只允許來自自己的網站。
- **GitHub Pages 不能設定伺服器回應標頭**，所以 CSP 用 `<meta>` 設定，`frame-ancestors`（防止網站被嵌入其他網站）無法生效。正式版若改用 Cloudflare Pages、Netlify 等可設定標頭的服務即可補上。

## 2. 端對端測試（Playwright）

21 個測試，在模擬手機上操作正式打包後的網站；外部服務一律使用模擬資料。連續重複執行 3 次（63 次）全部通過。每次部署前會自動執行。

| `e2e/security.spec.ts`   | XSS、錯誤資料被略過、另一位使用者看不到、CSP 擋下外部連線                      |
| `e2e/mobile.spec.ts`     | iPhone SE、iPhone 13、iPhone 15 Pro Max、Pixel 7：沒有左右捲動、按鈕至少 44×44 |

## 3. 效能

模擬「慢速 4G 網路 + 手機 CPU 慢 4 倍」：

| 頁面   | 首次看到內容（FCP） | 主要內容出現（LCP） | 版面位移（CLS） | 下載量 |
| ------ | ------------------- | ------------------- | --------------- | ------ |
| 地圖   | 1.4 秒              | 1.5 秒              | 0.011           | 146 KB |
| 回報頁 | 1.6 秒              | 1.6 秒              | 0               | 145 KB |

Google 的「良好」標準：LCP < 2.5 秒、CLS < 0.1，兩頁都達標。（不含地圖圖磚的下載時間，圖磚由 OpenStreetMap 提供。）

## 4. 監控與錯誤追蹤

**本版本不設定。** 原因：錯誤追蹤服務（例如 Sentry，有免費方案）需要註冊帳號，而且會把錯誤資訊（可能包含使用者操作內容、裝置資訊）送到第三方，依專案規範需要另外取得同意。示意版使用者少，可以直接回報問題。正式上線時建議加入。
